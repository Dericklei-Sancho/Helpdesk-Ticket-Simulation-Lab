Helpdesk Ticket Simulation Lab

Overview
This repository contains realistic IT Support and Helpdesk incidents simulated within a Windows Active Directory environment.

The objective of this lab is to demonstrate troubleshooting methodology, user support processes, Active Directory administration, DNS troubleshooting, Group Policy troubleshooting, and access management.
