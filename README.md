Helpdesk Ticket Simulation Lab
Overview
This repository contains realistic IT Support and Helpdesk incidents simulated within a Windows Active Directory environment.

The objective of this lab is to demonstrate troubleshooting methodology, user support processes, Active Directory administration, DNS troubleshooting, Group Policy administration, access management, and root cause analysis.

The incidents documented in this repository were performed within a custom Active Directory lab environment consisting of:

Windows Server 2025 Domain Controller
Active Directory Domain Services (AD DS)
DNS
Security Groups
Shared Folder Permissions
Group Policy Objects (GPO)
Windows 11 Domain-Joined Client
