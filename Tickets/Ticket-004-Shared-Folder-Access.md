Ticket 004 - Shared Folder Access
Priority
Medium

Category
Permissions Management

Issue Description
User required access to the Finance shared folder.

Investigation
Reviewed shared folder permissions.
Verified security group membership.
Confirmed access requirements.
Root Cause
User account was not assigned the correct permissions through the security group.

Resolution
Added user to Finance_Group.
Verified NTFS permissions.
Confirmed shared folder permissions.
Result
User successfully accessed the Finance shared directory.

Skills Demonstrated
Access Management
Security Groups
NTFS Permissions
Active Directory Administration
