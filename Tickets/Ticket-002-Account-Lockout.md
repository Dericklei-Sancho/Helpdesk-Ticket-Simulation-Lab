Ticket 002 - Account Lockout
Priority
Medium

Category
Account Management

Issue Description
User john.hr reported that the account was locked after multiple failed login attempts.

Investigation
Opened Active Directory Users and Computers.
Reviewed account status.
Confirmed user account lockout.
Root Cause
Multiple failed authentication attempts triggered the lockout policy.

Resolution
Unlocked account within Active Directory.
Advised user to verify password before retrying authentication.
Result
User successfully logged back into the domain.
