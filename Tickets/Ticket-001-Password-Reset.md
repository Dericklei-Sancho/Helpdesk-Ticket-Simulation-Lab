Ticket 001 - Password Reset

Priority
Medium

Category
Active Directory

Issue Description
User john.hr reported being unable to sign in to the domain account.

Investigation
Confirmed account existed within Active Directory.
Verified workstation connectivity to the domain.
Tested authentication using the current password.
Root Cause
User forgot the current password.

Resolution
Opened Active Directory Users and Computers.
Located user account john.hr.
Reset password.
Provided temporary password to the user.
Result
User successfully authenticated to the domain and regained access to the workstation.

Skills Demonstrated
Active Directory Administration
Password Management
User Support
Troubleshooting
