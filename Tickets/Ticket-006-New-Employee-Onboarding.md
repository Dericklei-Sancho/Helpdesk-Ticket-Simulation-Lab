Ticket 006 - New Employee Onboarding
Priority
Medium

Category
User Provisioning

Issue Description
A new Finance employee required access to company resources, domain authentication, and department-specific permissions.

Investigation
Reviewed onboarding requirements and department assignment.

Verified appropriate Organizational Unit and Security Group structure existed within Active Directory.

Root Cause
A new user account had not yet been provisioned.

Resolution
Created user account: kelly.finance
Assigned temporary password
Added account to Finance Organizational Unit
Added user to Finance_Group
Verified account visibility within Active Directory
Result
User account was successfully created and prepared for first-time login.

Active Directory Administration
User Provisioning
Group Management
