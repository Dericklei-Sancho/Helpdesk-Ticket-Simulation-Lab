Ticket 007 - Employee Offboarding
Priority
Medium

Category
Account Management

Issue Description
An employee departed the organization and required immediate removal of domain access.

Investigation
Reviewed Active Directory account information and verified employee details.

Root Cause
User account remained active after departure.

Resolution
Located user account mark.sales
Disabled account within Active Directory
Confirmed account status changed to disabled
Result
Domain access was successfully revoked and the account was prevented from further authentication.

Skills Demonstrated
Active Directory Administration
Security Management
Account Management
Access Control
